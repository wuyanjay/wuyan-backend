# QQ邮箱SMTP配置指南

## 一、获取QQ邮箱授权码

### 步骤1：登录QQ邮箱
1. 打开浏览器，访问 [QQ邮箱](https://mail.qq.com/)
2. 使用您的QQ账号和密码登录

### 步骤2：开启SMTP服务
1. 登录后，点击顶部导航栏中的 **设置**
2. 在左侧菜单中选择 **账户**
3. 向下滚动找到 **POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务** 区域

### 步骤3：生成授权码
1. 找到以下两个选项并开启：
   - ✅ POP3/SMTP服务
   - ✅ IMAP/SMTP服务
2. 点击 **生成授权码** 按钮
3. 按照提示，使用绑定的手机发送短信验证
4. 短信发送成功后，系统会生成一个 **16位授权码**
5. 复制此授权码，稍后用于配置

**重要提示：** 授权码只显示一次，请妥善保存。如果丢失，需要重新生成。

## 二、配置系统环境变量

### 步骤1：编辑.env文件
1. 打开项目根目录下的 `.env` 文件
2. 找到SMTP配置部分
3. 更新以下配置项：

```env
# SMTP Configuration (QQ邮箱配置)
SMTP_HOST=smtp.qq.com
SMTP_PORT=587
SMTP_USER=your-qq-email@qq.com    # 替换为您的QQ邮箱地址
SMTP_PASS=your-qq-authorization-code  # 替换为您刚才获取的16位授权码
SMTP_FROM_EMAIL=your-qq-email@qq.com  # 替换为您的QQ邮箱地址
SMTP_FROM_NAME=Auth System
```

**配置说明：**
- `SMTP_HOST`: QQ邮箱SMTP服务器地址，固定为 `smtp.qq.com`
- `SMTP_PORT`: 端口号，建议使用 `587` (TLS加密)
- `SMTP_USER`: 您的QQ邮箱完整地址
- `SMTP_PASS`: QQ邮箱授权码（不是QQ密码）
- `SMTP_FROM_EMAIL`: 发送邮件显示的发件人邮箱
- `SMTP_FROM_NAME`: 发送邮件显示的发件人名称

## 三、测试邮件发送功能

### 步骤1：运行测试脚本
1. 打开终端，进入项目根目录
2. 运行以下命令测试邮件发送：

```bash
node test-email.js
```

### 步骤2：检查测试结果
- 如果看到 `✅ 测试邮件发送成功！` 提示，说明配置正确
- 登录您的QQ邮箱，检查收件箱是否收到测试邮件

### 步骤3：排查问题
如果测试失败，请检查以下几点：
1. 确保QQ邮箱的SMTP服务已开启
2. 确保授权码正确，没有空格或换行
3. 确保 `.env` 文件中的配置项填写正确
4. 检查网络连接是否正常
5. 查看终端输出的错误信息，根据提示进行调整

## 四、常见问题及解决方案

### 问题1：授权码生成失败
**解决方案：**
- 确保您的QQ账号已绑定手机号
- 确保您发送的短信内容正确
- 如仍有问题，请联系QQ邮箱客服

### 问题2：邮件发送失败，提示认证错误
**解决方案：**
- 检查 `SMTP_USER` 是否为完整的QQ邮箱地址
- 检查 `SMTP_PASS` 是否为正确的授权码，不是QQ密码
- 确保授权码没有过期（如果长期未使用，可能需要重新生成）

### 问题3：邮件发送成功，但收件人收不到
**解决方案：**
- 检查收件人邮箱地址是否正确
- 检查邮件是否被标记为垃圾邮件
- 检查QQ邮箱的发送配额是否已满

## 五、生产环境配置建议

1. **定期更新授权码**：建议每3-6个月重新生成一次授权码，提高安全性
2. **使用专用发送邮箱**：为了避免主邮箱被封，建议使用专门的邮箱账号用于系统发送邮件
3. **配置DKIM和SPF**：如果您有自己的域名，建议配置DKIM和SPF记录，提高邮件送达率
4. **监控邮件发送状态**：定期查看邮件发送日志，及时发现和解决问题
5. **设置合理的发送频率**：避免短时间内发送大量邮件，防止被邮箱服务商封禁
